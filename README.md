# 🐐 Proof Frame · Нотолгоо хүрээ

<p align="center"><img src="assets/poster.jpg" width="300" alt="Proof Frame · Нотолгоо хүрээ"></p>

**Claude Code дотор ажилладаг видео эдитийн skill.** Өмнө ба дараа нь гэсэн хоёр утасны дэлгэцийг зэрэгцүүлж, сэтгэгдэл, том гарчиг, үнийн шошготой зар болгоно.

Reels, TikTok-д бэлэн 1080×1920 MP4 гаргана. GOAT Academy-гийн 14 эдитийн стилийн нэг.

---

## Юунд тохирох вэ?

- **Тохирно:** ажлын үр дүнг харуулах: үсчин, салон, хумс, машин угаалга, засвар, эдит хийдэг хүмүүс
- **Тохирохгүй:** өмнөх бичлэггүй бол. Жин, арьс, биеийн өмнө/дараа зураг Meta-гийн төлбөртэй зард хориотой байж болно

## Шаардлага

- **Claude Code** (desktop app эсвэл terminal), Claude Pro / Max эрхтэй
- **Mac эсвэл Windows**
- **ffmpeg** болон **uv**. Байхгүй бол Claude өөрөө шалгаад, суулгах командыг хэлж өгнө.

---

## Суулгах

**Хамгийн хялбар:** Claude Code-оо нээгээд энэ мөрийг хуулж бичнэ:
```
Энэ plugin-ийг суулгаад өг: https://github.com/SaagiiSG/goat-proof-frame
```
Claude өөрөө суулгана. Дараа нь `/reload-plugins` гэж бичих эсвэл Claude Code-оо хаагаад дахин нээнэ.

**Эсвэл өөрөө:** Claude Code дотор энэ 2 мөрийг ээлжлэн бичнэ:
```
/plugin marketplace add SaagiiSG/goat-proof-frame
/plugin install goat-proof-frame@goat-proof-frame
```

**Zip файлаар авсан бол:**
1. `goat-proof-frame.zip`-ийг задална. Задалсан `goat-proof-frame` хавтсаа устгалгүй үлдээгээрэй.
2. Claude Code-д "Энэ хавтсан дахь plugin-ийг суулгаад өг:" гэж бичээд задалсан `goat-proof-frame` хавтсаа чирж оруулна.
3. `/reload-plugins` гэж бичнэ.

**Шинэ хувилбар гарвал:** Claude-д "goat-proof-frame plugin-ийг шинэчил" гэж хэлэхэд болно.

> **For Claude Code:** to install this plugin, run `claude plugin marketplace add SaagiiSG/goat-proof-frame` (or, from an unzipped copy, `claude plugin marketplace add <path to the goat-proof-frame folder>`) and then `claude plugin install goat-proof-frame@goat-proof-frame`, then tell the user to type `/reload-plugins`. To update it: `claude plugin marketplace update goat-proof-frame` and then `claude plugin update goat-proof-frame@goat-proof-frame`.

## Хэрэглэх

1. Видео бүрд **шинэ хоосон хавтас** үүсгэ.
2. Claude Code-ийг тэр хавтсанд нээ.
3. Бичнэ: `/goat-proof-frame:goat-proof-frame` эсвэл энгийнээр: **"өмнө ба дараа нь гэсэн зар хийгээд өг"**
4. Бичлэгээ чирж оруулаад "өмнө" болон "дараа" бичлэгээ, сэтгэгдэл, гарчиг, үнээ бичнэ.
5. Claude юу хийхээ товч хэлнэ. Таалагдвал "ок" гэхэд л болно.
6. `output/proof-frame.mp4` бэлэн. Instagram, TikTok руу шууд оруулна.

## Дуу

- **Дуу эффект** автоматаар орно. Кодоор хийсэн учир лицензийн асуудалгүй. Хэрэггүй бол "дуу эффектгүй болго" гэж хэлэхэд болно.
- **Өөрийн дуугаар ярих (voice-over):** утсаараа дуугаа бичээд (voice memo) өгнө. Таны дуу гарах үед бичлэгийн дуу, хөгжим өөрөө намсна.
- **Хөгжим:** Instagram, TikTok апп дотроос нэмбэл зохиогчийн эрхийн асуудалгүй.
